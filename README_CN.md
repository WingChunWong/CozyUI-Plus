# 主要特性

### 🧪 酿造台配方

所有酿造配方均在界面中直观显示，便于快速查阅。

### 📚 附魔图标

附魔书会在提示中于附魔名称旁显示小图标。

### 🎨 OptiGUI 集成

为不同颜色的潜影盒、投掷器、发射器和末影箱添加了彩色背景。

### 🔤 增强字体

内置字体优化:

- **[Emoji+](https://github.com/Fogg05/Emoji-Plus):** FluentEmoji 替代方案

- **[MCsans+](https://github.com/Fogg05/MCsans-Plus):** 高清 NotoSans 字体

### 🌈 RGB经验条

在物品栏选择框和经验条上实现平滑缓慢的 RGB 循环效果，营造舒缓视觉体验。

### ✨  动态 UI 元素

流畅的按钮动画与界面过渡效果（**游戏版本**需 ≥ `1.21`）
