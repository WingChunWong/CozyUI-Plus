# Key Features

## 🧪 Brewing Stand Recipes
All brewing recipes are visually displayed on the interface for easy reference.

## 📚 Enchantment Icons
Enchanted books now display small icons next to enchantment names in tooltips.

## 🎨 OptiGUI Integration
Color-coded backgrounds for different colored shulker boxes, droppers, dispensers, and ender chests.

## 🔤 Enhanced Fonts
Built-in font improvements:
- **[Emoji+](https://github.com/Fogg05/Emoji-Plus):** FluentEmoji replacement
- **[MCsans+](https://github.com/Fogg05/MCsans-Plus):** High-definition NotoSans fonts

## 🌈 RGB Experience Bar
Smooth, slow RGB color cycling on inventory selection boxes and experience bars for a relaxing visual experience.

## ✨ Animated UI Elements
Fluid button animations and interface transitions (requires ≥ `1.21`)
